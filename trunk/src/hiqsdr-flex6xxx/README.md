# HiQSDR FLEX-8400 Gateway

Шлюз между приёмником HiQSDR и программами, использующими Flex SmartSDR API.
На текущем этапе проект определяется AetherSDR как FLEX-8400 и предоставляет
один приёмник Slice A. Он может работать в тестовом режиме без оборудования
или передавать команды управления настоящему HiQSDR.

## Структура

- `FlexControlServer` - discovery, TCP-команды Flex и состояние Slice A;
- `RadioBackend` - общий интерфейс управления приёмником, спектра и аудио;
- `TestRadioBackend` - тестовая реализация backend с генератором IQ;
- `TestIqSource` - временный генератор IQ вместо оборудования;
- `TestSignalProcessor` - временная обработка тестового IQ, спектра и аудио;
- `HiqSdrBackend` - адаптер команд управления реальным HiQSDR;
- `hiqsdr/HiqSdrDevice` - UDP-протокол управления HiQSDR (частота, входы и
  пины управления);
- `hiqsdr/HiqSdrIqReceiver` - приём сырых UDP IQ-кадров от HiQSDR;
- `VitaPacketBuilder` - создание пакетов VITA-49;
- `VitaUdpStreamer` - отправка VITA-49 клиенту;
- `Flex8400Emulator` - координация компонентов.

Flex API, VITA-49 и UDP-передача изолированы от реализации приёмника. Поэтому
при развитии поддержки HiQSDR не нужно менять протокольный слой Flex. Карта
поддержки команд и соответствия HiQSDR приведена в `docs/COMMAND_MAPPING.md`.

## Возможности

### Flex SmartSDR API

- отправляет discovery-пакет SmartSDR на UDP/4992;
- принимает TCP-соединения на порту 4992;
- создаёт один panadapter и один Slice A на 14.100 MHz;
- принимает настройку частоты Slice, USB-фильтра, входа ANT1/ANT2,
  предусилителя, аттенюатора, громкости и mute;
- принимает команды панорамы, keepalive, подписок и VITA UDP-потоков;
- эмулирует назначенный передающий Slice и статусы TX, но не включает PTT
  реального оборудования.

Поддерживается необходимый для AetherSDR стартовый обмен Flex (`V`, `H`, `C`,
`R`, `S`) и часть команд управления. Неизвестные команды журналируются и
возвращают ошибку Flex API, чтобы их можно было последовательно добавить.

### Тестовый режим

Без параметра `--hiqsdr-ip` запускается полностью автономный тестовый backend:

- VITA-49 спектр с белым шумом примерно `-73 dBm`;
- waterfall, использующий те же уровни, что и спектр;
- тестовая несущая и аудиосигнал, получаемые из одного IQ-источника;
- измеритель S-meter, вычисляемый по уровню в полосе выбранного фильтра;
- регулировка громкости и mute для RX-аудио.

Это временная модель сигнала, а не готовый DSP-тракт: переключение фильтра
влияет на попадание тестовой несущей в полосу, но FIR-фильтрация ещё не
реализована.

## Управление HiQSDR

Для управления реальным приёмником без IQ/DSP укажите его адрес:

```sh
./build/hiqsdr-flex6xxx --hiqsdr-ip 192.168.2.196
```

В этом режиме `HiqSdrBackend` передаёт устройству частоту, выбор входа,
предусилитель, аттенюатор и код преселектора. Он также принимает IQ-поток с
UDP-порта `48247`: запуск `0x72 0x72`, остановка `0x73 0x73`. Кадр имеет
размер `1442` байта: два служебных байта и 240 пар 24-битных IQ-отсчётов в
little-endian порядке.

Частота дискретизации выбирается по ширине панорамы, заданной AetherSDR через
`display pan set ... bandwidth=...`:

- до 40 кГц: `96 kS/s`;
- до 80 кГц: `192 kS/s`;
- до 200 кГц: `240 kS/s`;
- до 280 кГц: `320 kS/s`;
- до 400 кГц: `480 kS/s`;
- до 800 кГц: `960 kS/s`;
- до 1.6 МГц: `1.92 MS/s`.

При смене частоты дискретизации IQ-поток безопасно останавливается,
перенастраивается и запускается заново.

Преселектор задан таблицей диапазонов прямо в `HiqSdrBackend`; файл
`hiqsdr.cfg` для его выбора не нужен. Вне описанных любительских диапазонов
выбирается bypass. Из IQ строятся 1024-точечные FFT-спектр и waterfall для
текущих частоты и ширины panadapter. Преобразование выполняется с окном Hann;
абсолютная шкала dBm пока предварительная и будет откалибрована отдельно.
RX-аудио, фильтрация и демодуляторы пока не реализованы, поэтому аудио в
AetherSDR остаётся пустым. PTT также не включён.

## Тестовый сигнал

Внутренний IQ-источник содержит несущую на `14.125000 MHz`. В режиме USB
приёмный звук появляется, когда Slice A настроен в диапазон `14.122100` -
`14.124900 MHz`. Например, при `14.124300 MHz` слышен тон около 700 Hz.

## Сборка

```sh
cmake -S . -B build
cmake --build build
./build/hiqsdr-flex6xxx
```

Полная команда запуска с IP HiQSDR и адресом, доступным для AetherSDR:

```sh
./build/hiqsdr-flex6xxx --hiqsdr-ip 192.168.2.196 --address 0.0.0.0 --port 4992
```

## Журнал

Все сообщения шлюза, включая команды AetherSDR и ошибки UDP, записываются в
`logs/hiqsdr-flex6xxx.log` относительно рабочей папки. Другой путь можно
указать параметром `--log-file`:

```sh
./build/hiqsdr-flex6xxx --hiqsdr-ip 192.168.2.196 --log-file /tmp/hiqsdr-flex6xxx.log
```

Для подключения с другой машины укажите адрес интерфейса:

```sh
./build/hiqsdr-flex6xxx --address 192.168.1.10
```
